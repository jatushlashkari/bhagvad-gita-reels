# Bhagavad Gita Reels

Fully automated daily reels: one Gita verse a day, rendered with Remotion (Sanskrit shloka + Hindi/English meaning + Hindi voiceover + music) and auto-posted to YouTube Shorts and Instagram Reels by GitHub Actions.
